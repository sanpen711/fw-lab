隐私政策

本政策说明 FW研究所如何处理账号资料、社区与聊天内容、会员订单及周边配送信息，适用于实际提供相应功能的 Windows 客户端、网页和 PWA。

生效日期：2026年7月10日　最近更新：2026年10月29日
联系邮箱：674740680@qq.com

1. 适用范围

本政策适用于 FW研究所的 Windows 客户端、网页及 PWA 中实际提供的账号、社区交流、会员和周边商城服务。本服务由 YSP启元工作室提供与维护。不同版本提供的功能可能不同，相应信息仅在你使用对应功能时处理。

2. 我们处理哪些信息

账号资料：注册或登录使用的邮箱、账号标识、实验品编号、昵称、头像、账号状态及登录验证记录；密码和验证码通过账号认证流程处理。

内容与互动：你主动提交的帖子、评论、图片、表情、投票及投票记录、闲聊房间资料与消息、搭子关系、一对一聊天消息、游戏组队资料、通知、举报和问题反馈。

会员与订单：会员方案、权益、装扮设置、开通与到期时间，以及订单号、购买项目、金额、支付状态、支付平台返回的交易编号和处理时间，用于开通权益、核对支付及处理订单问题。

收货与配送：仅在购买需要配送的周边商品时，处理你填写的收货人姓名、联系电话、详细地址，以及承运方、物流单号和发货状态，用于订单履约与售后。

运行与本地数据：为维持登录、记录必要的用户活动、排查故障和保障安全，服务会处理必要的访问时间、连接信息及错误日志；网络服务方会收到请求的 IP 地址等连接信息。设备上会保存登录会话、用户设置、草稿、部分内容缓存及小游戏进度等本地数据，Windows 客户端还使用本地数据库缓存。

3. 使用目的与必要性

上述信息用于注册与登录、邮箱验证和密码找回、展示个人资料与用户内容、提供社区互动和聊天、管理房间与组队、发送站内通知、开通会员、处理支付与配送、受理举报反馈，以及保障账号安全和服务稳定。我们不会以出售个人信息为目的处理这些数据。

账号信息是使用登录服务所必需的。帖子、图片、聊天和反馈由你主动提交；会员购买和周边收货信息仅在使用相应功能时需要。你可以选择不使用这些可选功能。

4. 内容的可见范围与管理

你公开发布的帖子、评论、话题、投票及组队资料，会按相应页面的访问规则向其他用户或访问者展示。昵称、头像和相关公开个人资料可能随内容一起展示。使用昵称或临时笔名不等于平台无法关联到账号，请勿发布本人或他人的敏感个人信息。

闲聊房间消息供具有访问权限的房间成员查看，房间的密码和申请加入规则影响加入权限。一对一聊天消息面向聊天参与者，不在公共页面展示。举报、反馈和收货资料不作为公开社区内容展示。

为处理举报、账号异常、安全事件、订单履约和必要的故障排查，管理员可在其权限和处理目的所需的范围内接触相关内容与记录。社区提供举报和拉黑等功能；具体处理方式以应用内规则及实际处理结果为准。

5. 第三方服务与必要提供

Supabase：提供账号认证、数据库、文件存储及相关后台服务，处理提供这些功能所需的账号资料、用户内容、社交记录和订单等信息。

腾讯云邮件推送：用于注册验证和密码找回，处理收件邮箱、验证码及邮件模板参数。你自己的邮箱服务商也会处理收到的邮件。

支付宝：用于会员和周边商品付款，接收交易所需的订单号、商品说明及金额等信息，并返回支付状态、交易编号等结果。支付环节还适用支付宝自身的服务规则和隐私说明。

配送服务：购买实物商品后，发货人员及实际承运方会在完成配送和售后所必需的范围内使用收货姓名、电话、地址与物流资料，承运方可在订单物流信息中查看。

GitHub Pages：用于托管和分发网站静态页面，访问页面会向托管服务发送必要的网络请求及连接信息。

除上述服务协作、你主动公开或指定提供的信息，以及法律要求的情形外，如需向其他独立第三方提供个人信息，我们将按适用要求另行告知并取得所需同意。

6. 存储地点、本地缓存与安全

目前 Supabase 项目配置在美国东部区域（us-east-1），相应账号、社区及订单数据通过该项目处理和存储；腾讯云邮件投递服务配置使用中国香港区域。因此，本服务的数据处理并非全部发生在中国大陆境内。使用账号、社区及订单功能时，相应信息会经网络传输至该项目进行处理；注册验证及密码找回邮件通过上述香港区域的邮件服务投递。

本地缓存和用户设置保存在你使用的设备上。Windows 客户端可通过设置中的清理缓存功能清理相应应用缓存；退出登录、清理浏览器站点数据或卸载应用会影响本机数据，但这些操作不等于注销服务端账号。

服务通过加密传输、账号认证、访问权限和管理权限隔离等措施降低信息泄露、篡改和丢失风险。请保管账号密码、验证码及设备，并谨慎处理聊天记录、截图和公开发布内容。

7. 保存、账号注销与删除

账号存续期间，系统保存提供相应功能所需的信息。你删除本人内容或注销账号后，相关账号资料、帖子、评论、社交关系、聊天和个人文件会按照实际删除流程清理；已被其他用户下载、截图或另行保存的副本不受平台直接控制。

周边商城订单采用独立的交易记录。账号注销时会解除订单与账号的关联，但不会自动一并删除订单中的商品、交易、收货和物流记录。相关记录仍用于履约、售后、对账、安全审计及适用的法定保留义务。对不再需要或超过适用期限的信息，可通过下述联系渠道提出删除请求，由我们核实并处理。

我们按提供服务、处理交易及履行适用义务所必需的期限保存信息，不作“注销即删除所有数据”的承诺。对依法仍需保留或尚待完成履约的信息，将限制其使用范围；满足删除条件后处理删除或匿名化。

8. 你的选择与联系渠道

你可以在个人资料和设置中修改昵称、头像等资料，通过登录页的找回密码流程重设密码，并使用对应页面提供的本人内容删除、举报和拉黑功能。

访问、复制、更正、删除个人信息、注销账号或其他隐私请求，可通过提供相应功能的账号页面办理，也可发送邮件至 674740680@qq.com。无法登录时仍可通过此邮箱联系。我们会核实请求人与账号或订单的关系，并按照适用要求处理；请勿在邮件中发送密码或验证码。

9. 未成年人及政策更新

本服务主要面向上班族等一般用户，不以不满14周岁的儿童为主要服务对象。未成年人使用服务及购买商品或会员时，应取得监护人的指导和适用要求下的同意，不应公开能够识别本人或他人的敏感信息。监护人发现相关信息处理问题，可通过公开联系邮箱提出请求。

政策更新会在本页面或应用内说明，重要变化会通过相应公告提示。涉及需要另行告知或取得同意的处理事项，将按适用要求处理。请以本页注明的最近更新日期识别当前版本。
