# 电脑端会员等级

等级只显示 V1～V9。会员功能均从 V1 开始使用；成长解锁静态装扮，不提高发帖、评论或组队权限。以下日期阈值均为累计**实际有效会员时间**，每 86400 秒计一天。

| 等级 | 累计有效天数 | 展示或解锁 |
| --- | ---: | --- |
| V1 | 开通即达 | 会员徽章、现有头像框与资料卡、全部会员功能 |
| V2 | 30 | 等级徽章 |
| V3 | 90 | 月桂头像框 |
| V4 | 180 | 典藏资料卡 |
| V5 | 365 | 伏伏头像框 |
| V6 | 540 | 星轨头像框 |
| V7 | 730 | 绶带头像框 |
| V8 | 1095 | 荣誉资料卡 |
| V9 | 1460 | 冠冕头像框 |

预付的未来时长不提前计入。有效期结束后自动截断累计；取消会员时结算已经过的时间。续费从当前时间恢复计算，未续费的间隔不计入。已达到的等级保留，公开徽章、头像框和资料卡只在会员有效期内显示。

`private.membership_growth` 保存已结算秒数和当前计时区间；会员表的触发器在同一事务内结算和续接区间。`fw_get_own_membership_growth()` 只返回当前登录账号的等级、有效天数及下一门槛。`fw_get_membership_levels(uuid[])` 最多接受 200 个账号，只返回有效会员的最小公开等级信息。

当前可核实的历史会员区间会补算，旧会员表没有记录的更早间断历史不会推测补发。数据库拒绝客户端直接更改累计秒数，也拒绝未达到等级或会员已过期时保存专属装扮。公开入口为 SECURITY INVOKER，带权限的实现置于 private schema，并检查登录及封禁状态。

迁移：`migrations/20261009090502_membership_growth_v1_v9.sql`，时间戳与线上迁移记录一致。回归：`tests/membership-growth.sql` 和 `tests/alipay-membership.sql`，两者均创建合成测试数据并全量回滚。电脑端付款、订单和身份展示使用后台结果，不自行增加会员时长或等级。

本次安全检查没有新增公开提权函数或匿名权限。私有累计表启用 RLS 且没有客户端策略，是有意拒绝直接读取；该信息级提示的说明见 [Supabase RLS 检查](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy)。现有其他模块的权限提示不在本次修改范围。
